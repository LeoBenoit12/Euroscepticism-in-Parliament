# Replication Code

This repository holds the code for a paper currently under review.

In the `final_regression` folder, the file `regression_prep.md` corresponds to the data processing pipeline taking the machine-coded parliamentary speeches and inputing the dataframe used in the regression analysis (`reg_data_tri`). The file `regression_final.md` then takes this processed data and conducts the regression analysis. It also creates descriptive statistics and, for the benchamrking of our measure against the Chapel Hill Expert Survey, uses yearly positional estimates, created in `regression_prep.md`. 

Both Markdown files render with corresponding tables and images. RMarkdown versions in raw code are also displayed.
